# Prototype

Unity prototype project for CTIN 526.

## Requirements

- Unity `6000.3.6f1`

## Getting started

1. Clone this repository.
2. In Unity Hub, choose **Add > Add project from disk**.
3. Select the cloned repository folder.
4. Open it with Unity `6000.3.6f1`.

Unity will recreate the ignored `Library` folder the first time the project is opened.

## Collaboration

Pull the latest changes before starting work. Avoid editing the same Unity scene or prefab at the same time when possible, because those files can produce merge conflicts.
